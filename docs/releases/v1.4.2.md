# StayLit 亮屏助手 v1.4.2

首个面向 GitHub 的开源发布，采用 MIT 许可证。

## 功能

- 定时保持亮屏，倒计时结束发送息屏指令；支持自定义时长和常用预设。
- 一直亮屏并实时记录本次时长，保留最近一次任务的开始和结束时间。
- 一键立即息屏、托盘运行、单实例。
- Windows 浅色、纸白、石墨黑三套主题；默认 Windows 浅色，自动保存选择。

## 本次修复

移除数字输入框内隐藏的原生箭头区，修复窗口重开或显示恢复后可能出现的黑色竖条，保留键盘和加减操作。

## 下载和运行

下载 StayLit-1.4.2-win.zip，解压后双击 StayLit-1.4.2.exe，无需安装或管理员权限。需要 Windows 10 / 11 和 .NET Framework 4.8 或更高版本。

若旧版仍在运行，请先在旧版托盘菜单选择“退出”。

## 验证

33 项自动检查通过，包含模拟电源和恢复后的重绘检查。自动检查不会实际关闭显示器，不能等同于真实硬件的息屏唤醒验证。已检查本机 150% 显示缩放下的三套主题。

SHA256SUMS.txt 提供下载文件校验值。源码可使用仓库的 build.ps1 构建，无第三方运行依赖。
